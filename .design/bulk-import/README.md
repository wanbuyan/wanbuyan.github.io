# 水浒插图批量整理记录

本批来自桌面“水浒插图”：原编号 001.jpeg–181.jpeg，共 181 张、11,342,215 字节。按原图题名识别人名或群像；同一人物多个造型按原编号先后加 -01、-02 等后缀。图片字节保持不变，导入后对源文件和网站副本逐张核对 SHA-256。

## 题字描述

描述已从首轮短摘录补充为按原图左侧或右侧文字整理的题字，繁体转简体、补标点和书名号，保留能辨认的人物说明、造型点评、诗句、日期和署款。网页中的 `〔未辨〕` 表示尚未确认的字句；具体位置记录在 `manual.json` 的 `transcription_notes` 和 `题字整理.md`。没有另写人物故事，也不使用小说常识替代原图文字，不直接发布 OCR 输出。

181 张均重新核对侧栏，包含人物及群像共 160 种名称。部分图片本来只有题名、回目与署款，按原有文字录入。含缺字的记录标为 `transcribed_with_gaps`；其余标为 `readable_side_text_transcribed`。这不表示完整题跋已经全部无误识别，仍有字句需要进一步校对。

修正了初次识别中的苏东坡（027）、凌振（053）、孙立（070）、邓飞（071）等题名。群像如“梁山卒儿”“宋庭官军士卒”“衙役差拨”沿用原图题名。

本轮再核对时，更正“渔夫艄公”为“渔夫艄童”（174），两处图片文件名同步修正；纠正阎婆惜（147）首轮误读，原题是“画妇人不易，画美人更难”，不是先前误写的诗句。张文远（142）的“同房押司”“风流茶说合，酒是色媒人”及原题回数也已更正。回数按原图题字抄录，不根据小说章回自行改动。

## 文件

- `命名与描述对照.csv`：原名、新名、已确认描述、完整题跋状态、校验值；同一份也保存在桌面源文件夹。
- `catalog.json`：完整导入记录。
- `manual.json`：当前名称、已确认描述及校对状态。
- `expanded-*.json`：本轮重新核图后的较长题字，括号中保留具体待核位置。
- `题字整理.md`：181 张图片当前题字及具体待核位置，便于人工继续校对。
- `描述补充对照.csv`：旧描述与本轮补充后描述。
- `description-expansion-result.json`：前后可辨字符统计，不计缺字说明。
- `reviewed-excerpts*.json`：本轮放大复核后的节选；`finalize_review.py` 合并并应用保守修正。
- `inventory.json`：导入前的编号、尺寸、大小和 SHA-256。
- `ocr-raw.jsonl`、`ocr-modern.jsonl`：本地 OCR **未校对草稿**，不能作为准确文本使用。
- `ocr-server-review.jsonl`：另一种本地识别模型的复核草稿，同样不直接用于网页。
- `manual.json` 中 `chapter_draft` 为初轮未核稿，**不参与网页生成**。
- `labels-*`、`sides-*`、`title-*`：人工校对的局部放大图，不是网站依赖。
- `build_catalog.py`、`apply_catalog.py`：本次整理工具，网站运行不需要 Python。

实际网站共用目录为 `assets/artworks.js`，资料副本位于 `资料/水浒人物/`。主页随机抽取两张不同文件，显示各自名称和描述；同一人物的不同造型作为独立图片参与抽取。
