# 金句字体预览

保留现有金句结构、暖白底、正文与出处层级，仅比较四种真实字形。预览不修改主页样式。

参考字样：

- [Noto Serif SC](https://fonts.google.com/noto/specimen/Noto+Serif+SC)：宋体的笔画对比，适合清晰的书刊式展示。
- [KaiTi](https://learn.microsoft.com/en-us/typography/font-list/kaiti)：端正的楷书字形，作为本次古诗词金句的首选方向。
- [STFangsong](https://learn.microsoft.com/en-us/typography/font-list/stfangsong)：细长的仿宋字形，留白感较强。
- [STXingkai](https://learn.microsoft.com/en-us/typography/font-list/stxingkai)：行楷笔意明显，作为更偏书法的候选。

色彩沿用暖白 #f8f7f3、正文 #292a26、说明 #717368，朱红 #a93627 仅用于样式编号。四组正文均为 32px、400 字重、1.85 行高、.025em 字距，出处均为 13px，同样的文案和宽度；窄屏改为 25px 与自然换行，避免把字号差异当成字体差异。

比较页面为 `quote-font-preview.html`，使用本机字体，不复制系统字体文件。无自动播放或额外动效。最终采用哪一种字体由用户选择，正式页面实现时再处理跨设备的字体加载与回退。
