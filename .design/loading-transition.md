# 加载转场

依据用户确认的浅色书刊风预览实现。暖白 #f8f7f3、墨色 #292a26、朱红 #a93627。标题使用系统宋体，界面文字使用系统无衬线字体，不增加字体下载。桌面标题 40px，手机 32px；站名 18–20px，状态 16px。三个 6px 圆点以 140ms 错峰轻微起伏，幅度 5px，周期 1100ms。文字和圆点 360ms 缓入，完整展示至少 1600ms，再以 420ms 缓出。减少动态效果设置下保留渐变和最短展示时间，圆点使用不含位移的明暗变化，避免完全无动画。转场资源带版本号，更新时避免沿用旧缓存。

用于象棋和贪吃蛇。博客的普通点击先在当前页面淡入加载层，360ms 渐入完成后在同一标签页进入游戏。通过临时时间戳传递加载起点，目标页接续同一标题与加载画面，不重复渐入；时间戳随后从地址栏清除。直接访问游戏时仍执行完整渐入。保留 Ctrl/Command 点击、中键等浏览器原生打开方式。

等待 DOM 与游戏初始化完成，再进入游戏。从首次显示开始计算缓入和最短展示时间，避免资源快加载时连续闪屏；资源更慢时继续等待，没有虚假百分比。淡出时沿用同一加载弹窗，不再关闭后重开，避免露出中间画面。游戏的开始弹窗保持原有状态，加载层退出后恢复可操作性。

加载失败显示重试；12 秒仍未完成时提示较慢，并提供重新加载或返回博客。离开页面时清理加载层，避免浏览器后退恢复到遮挡状态。文件均为本地静态资源，不引入库或启动脚本。

首次绘制：两个游戏在外部样式请求前内联设置暖白背景，减少白色空白页切换到加载层的色差。渐入改用独立 Web Animations 时间轴，避免其他游戏弹窗置顶时重启透明度动画；保持透明度合成层，直到加载层离开。浏览器测试在渐入中途延迟弹出另一个对话框，逐帧检查透明度连续性。
