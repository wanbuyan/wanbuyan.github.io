# 发布帖子

网站保持纯静态，不需要启动脚本或后端。

已导入《DC-3全流程——万不言》（2026-11-24），正文与 28 张原始截图可从帖子栏目阅读，配图位于 `images/dc3/`；Word 原件位于 `资料/DC-3全流程——万不言.docx`，同时登记在资料仓库，帖子文末也可下载同一份文件。

已导入帖子《DC-2靶场全流程——万不言》，可从首页“最新帖子”或“帖子”栏目阅读。正文保存在 `posts.js`，14 张原始截图位于 `images/dc2/`（原文共引用 15 次），Word 原件位于 `files/`，文章末尾提供下载链接。该文档不再作为资料仓库的独立条目。

1. 用浏览器打开本文件夹的 `editor.html`。
2. 填写标题、文章标识、日期、分类、摘要和正文。文章标识使用英文字母、数字、短横线或下划线，例如 `my-first-post`。
3. 点击“保存并导出 posts.js”，下载的文件包含原有帖子和本次修改。
4. 用下载文件替换本文件夹中的 `posts.js`。注意浏览器可能把文件名改为 `posts (1).js`，替换时仍命名为 `posts.js`。
5. 将修改后的文件提交到 GitHub。Pages 部署完成后，刷新网站的“帖子”栏目。

编辑旧帖：在写帖工具顶部选择已有帖子。连续写多篇时，保存并导出后点击“新建下一篇”；最后导出的文件包含本次会话中保存的全部帖子。重新打开工具会读取网站当前的 `posts.js`，请先替换导出的文件。

草稿：勾选“保存为草稿”后，该条数据会保留在导出文件里，网站不展示。未导出的当前编辑内容暂存在当前浏览器，换浏览器或清理浏览器数据后不会保留。

配图放入 `posts/images/`，正文写 `![图片说明](posts/images/文件名.jpg)`。配图路径从网站根目录开始写；文件名不要包含空格。图片也需一并上传。

支持的 Markdown：标题、段落、粗体、行内代码、代码块、有序/无序列表、引用、链接和图片。HTML 以普通文字显示。

也可以直接编辑 `posts.js`：每篇帖子包含 `id`、`title`、`date`（YYYY-MM-DD）、`category`、`excerpt`、`content`，可选 `draft: true`。每个 id 必须唯一。帖子正文与列表都不需要联网加载，双击首页也可以阅读。
