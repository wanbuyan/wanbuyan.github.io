# 更新金句

只维护本文件夹中的 `金句.xlsx`，不需要修改网页代码，也不需要导出 JavaScript。

1. 用 Excel 或 WPS 打开 `金句.xlsx`。
2. 第一行保留 `出处`、`作者`、`内容` 三列表头，下面每行填写一条金句。可增删行，列的顺序可以调整；表头不可重复。
3. 保存为 `.xlsx`，文件名仍为 `金句.xlsx`。
4. 上传到 GitHub，覆盖网站 `金句/金句.xlsx`，等静态网站部署完成后刷新即可。

`内容` 必填。`出处`、`作者` 可以留空；出处可写“蝶恋花”，网页自动显示书名号，也可以自行填写《蝶恋花》。空白行跳过，完全相同的记录合并。正文按普通文字展示，不解析 HTML，也不执行 Excel 公式。

网站优先读取名为“金句”的工作表，否则读取第一张可见工作表。建议整个文件只保留这一张表。

## 更新规则

北京时间零点更新。金句每天一条，按打乱后的顺序展示，每轮内不重复。水浒插图每小时展示一组关联双图，优先同一人物的不同画像、亲属或搭档，也可按同一具体故事配对；图下显示关联说明。所有访客在同一小时看到相同插图、同一天看到相同金句，刷新不会重新抽选。

插图一轮内每张最多展示一次；未能配成对的图片优先安排到下一轮。不为补齐两张而使用无关图片，尚无已核对关联的图片仍保留在资料仓库。人物关系维护在 `assets/artwork-relations.js` 中，新增或修改关系、图集会重新生成排期。金句与图片独立轮换。

从北京时间 2026-11-23 零点起计算排期。无人访问也会推进。网页持续打开时，插图在每个整点切换，金句在零点切换；切回后台标签页时也会检查并更新。

同一份名单的展示顺序保持固定，重新打开不会重排。修改 Excel 的金句名单后，按新名单重新生成排期；旧版与新版之间不保留跨版本的已展示历史。仅改行顺序不会改变名单与排期。

模板目前只有晏殊《蝶恋花》一条，因此每天都会显示这条；增加更多金句后，就会轮换。

## 本地预览

双击首页打开时，浏览器不允许网页自行读取旁边的 Excel。展开页脚下方“本地金句预览”，选择此 Excel，即可在首页预览；该入口仅在本地打开时显示，线上访客看不到。浏览器允许保存时，会记住上次导入的数据；修改 Excel 后重新选择文件。

线上页面直接读取 Excel，不使用本地预览缓存。表格读取失败时保留已载入的金句，首次无数据时使用模板中的演示金句。
